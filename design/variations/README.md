# Stillpoint visual explorations

Three UI and matching app-icon concepts generated with the built-in imagegen tool. These are visual mockups; application code and installed icons have not changed. Generated Sanskrit, translations, dates, and controls are illustrative and must be verified or implemented separately.

1. `01-warm-editorial.png`: ivory surfaces, antique gold, editorial serif headings, mountain sunrise wallpaper, sun-and-horizon icon.
2. `02-indigo-stillness.png`: midnight navy, lavender typography, amber actions, twilight wallpaper, luminous point-and-orbit icon.
3. `03-ivory-sage.png`: pale sage and ivory, forest-green actions, native-style controls, misty forest wallpaper, lotus icon.

The warm editorial direction best preserves the existing app's visual character. All concepts explore language controls, display selection, daily scheduling and a visible next-change status.
