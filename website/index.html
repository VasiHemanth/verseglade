A few helpful notes

Getting settled.

Quick answers for installing and setting up Verseglade.

How do I install Verseglade?

Download the file for your operating system above, then open it and follow your system's prompts. On Linux, make the AppImage executable before opening it if your file manager asks.

Which macOS download should I choose?

The listed macOS disk image is for Apple silicon (aarch64) Macs. Check About This Mac to confirm your Mac uses an Apple chip.

Does Verseglade replace my wallpaper?

It uses your chosen image as the background and adds the quote to a locally prepared wallpaper image. Applying a quote to an animated wallpaper makes a still image.

Where can I get help?

For installation issues or questions, visit the project's GitHub issues.
